## Software that keeps working after launch day.

MARSO TECHNOLOGIES designs, builds and runs web, mobile and backend systems for companies that depend on them. One accountable team, from the first diagram to the production pager.

### Services

- **Product engineering** — Web applications, APIs and mobile apps, built to be maintained by people who did not write them.
  <br><sub>.NET · TypeScript · Angular · Next.js · Flutter</sub>
- **Architecture & consulting** — Design reviews, performance and security audits, and a clear plan for the system you already have.
  <br><sub>Architecture · Databases · Code review</sub>
- **Delivery & operations** — CI/CD pipelines, cloud infrastructure, monitoring and incident response — the part after the demo.
  <br><sub>CI/CD · Cloud · Observability</sub>
- **Brand, design & marketing** — Brand identity, product and web design, campaign art direction, motion and 3D — made next to the product, not handed over after it.
  <br><sub>Branding · UI design · Motion · Campaigns</sub>

### Approach

- **Scope in writing** — Every engagement starts with a written statement of work: what is built, how it is accepted, what it costs.
- **Small, frequent releases** — Working software you can try every week, not a big reveal at the end.
- **You own the code** — Source, documentation and infrastructure belong to you, in your repositories, from the first commit.
- **Plain invoicing** — Monthly invoices in USD or EUR under a standard services agreement.
